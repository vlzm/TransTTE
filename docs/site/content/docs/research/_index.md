# Research

This section reconstructs the scientific core of the PKDD'22 paper *"Logistics, Graphs,
and Transformers: Towards improving Travel Time Estimation"* ([arXiv:2207.05835](https://arxiv.org/abs/2207.05835)).

Read it in order:

1. **[Problem Formulation]({{< relref "/docs/research/problem-formulation" >}})** — the
   TTE task stated formally.
2. **[Related Work]({{< relref "/docs/research/related-work" >}})** — the two families of
   TTE methods and the baselines used for comparison.
3. **[Method]({{< relref "/docs/research/method" >}})** — the Graphormer-based model:
   centrality encoding, spatial encoding, and the attention bias.
4. **[Results]({{< relref "/docs/research/results" >}})** — the MAE/RMSE comparison on
   Omsk and Abakan, plus the picturesqueness/historicity routing objectives.

For how these ideas turn into a running system, continue to
[Architecture]({{< relref "/docs/architecture" >}}).
